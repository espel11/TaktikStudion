# Taktikstudion

Statisk fotbollsstudio med formationer, keyframes, motståndare och bild-/videoexport.

## Publicera på Vercel

1. Importera detta GitHub-repo i Vercel eller anslut det till ditt befintliga projekt under Settings → Git.
2. Välj Framework Preset: Other. Root Directory: repots rot. Ingen bygginstallation behövs.
3. Aktivera Web Analytics under Analytics → Enable.
4. Publicera eller välj Redeploy efter aktiveringen.
5. Besök produktionsadressen och kontrollera Analytics i Vercel.

Analytics-koden finns redan i index.html. Statistik börjar samlas efter att Analytics aktiverats och projektet publicerats igen. Ingen statistik verifieras genom att bara öppna filen lokalt. Annonsblockerare kan stoppa insamlingen.

Egna spelare och matchplaner sparas i webbläsaren. Exportera matchplanen från din gamla adress och importera den på den nya om du byter adress.

Öppna index.html lokalt för att använda appen utan installation. Behåll app.js och style.css i samma mapp.
